# 家庭内序列5位パパ（仮）

実話の「お父さんの悲哀」を、**毎回同じ型・同じ決め台詞**のアニメにする。
悲哀もの。でも**最後は見ている人がクスっと笑うオチ**で終わる。感動や逆転では締めない。
型は番組の顔（サザエさん方式）。中身は毎回ちがう実話なので量産型にはならない。

## 登場人物（家庭内の力関係）

| 序列 | キャラ | 設定 |
|---|---|---|
| 1位 | **妻** | ボブ。家庭の絶対王者。キッチンの番人（リフォーム後は汚れるのが嫌でパパはお湯を沸かすことしか許されない） |
| 2位（時々1位） | **息子**（10歳・男の子） | 家庭内の策士。義姉と義父に「あれやって」「これ買って」と遊びや買い物に付き合わせる。自分のスマホだと妻に使用時間がバレるので、義父のスマホでゲームやYouTubeを見ている |
| 3位 | **義姉**（妻のお姉さん・同居）★レア | メガネ。独身。アイドルの推し活中。義父に甘やかされる「娘」枠。息子にはよく使われる |
| 4位 | **義父**（妻の父）★レア | 白髪。娘2人のためなら何でもやってしまうほど優しい。孫にも甘い。優しさの基準が高すぎて、パパが比べられる原因になる。パパと4位・5位を争う、男同士の同志でもある |
| 5位（不動） | **パパ**（メガネ） | 毎日6時前に家を出て、高速で片道1時間半。家族で一番家にいないのに序列は最下位。口癖は「…まあ、いいんです。パパなので。」 |

**義父と義姉はレアキャラ。** 本編に出るのは数話に1回だけにして、出る回はタイトルや冒頭で「レア回」と分かるようにする。普段は洗濯物などの持ち物（推しTシャツ、肌着）でだけ存在を感じさせる。
会社の場面には、モブの**後輩**（`kohai`）を使ってよい。

パパが最下位なのは毎回の前提。動画の中で順位を発表したりランキングにしたりはしない（いつも同じ結果になるので）。

## トーンのルール
- **悲哀で積み上げて、最後はクスっとさせる。** 救い・感動・スカッとする逆転では締めない
- オチの型（どれか1つ）
  - **モノに負ける**：パパよりモノの方が大事にされている（例：パンツは助手席の暖房席、パパは運転席）
  - **第三者の一言**：何も知らない人が核心を突く（例：後輩「先輩、なんかイカ焼きの匂いしません？」）
  - **家族の無邪気な一言**：息子が悪気なくとどめを刺す（例：「パパ、それ食べれるの？」）
  - **冒頭に戻る**：最後のカットが冒頭のフックにつながり、また同じ目にあう
- 笑いはいつもパパ自身に向ける。家族を悪者にしない
- **リアルさ優先。** 実際に起きた場面・時間・場所・動作で描く（例：「タンスを開けたら」より「朝、シャワーを浴びようとしたら」）。生活の細部が具体的なほど共感される
- 対処やオチを作り話で足さない。足りないところは本人に「実際はどうしたか」「誰に何を言われたか」を聞く。脚色するときは本人に確認してから
- 家族は「パパを雑に扱うけど、本気では嫌っていない」。モラハラ・嫁いびり・虐待に見える描写はしない（企業案件が付かなくなる）
- 実在の店（焼肉キングなど）は好意的に描く。悲哀の原因はいつも家族側で、お店は悪くない
- 下ネタはパンツの一夜干し程度まで
- 実名・顔・住んでいる地域・学校・勤務先が分かる情報は出さない。息子は特に注意する
- 義姉の推しは架空のアイドルにする（実在のグループ名・メンバー名・ロゴは出さない）

## 決め台詞（毎回必ず使う）

| 場面 | 台詞 |
|---|---|
| 時報（冒頭） | 「現在、午前4時50分。家族はまだ、誰も起きていません。」（時刻はネタに合わせて変える） |
| 締め | 「…まあ、いいんです。パパなので。」 |

## ショート（45〜60秒）の型

| 秒 | パート | 中身 |
|---|---|---|
| 0〜3 | フック | 一番強い絵と一文。例：「パンツが、イカになっていた」。説明から入らない |
| 3〜9 | 時報 | 時刻のナレーションと、状況の一言 |
| 9〜30 | 事件 | 理不尽が積み重なる。セリフは短く、絵で見せる |
| 30〜41 | 対処と結果 | パパが仕方なく対処する（工夫や逆転ではなく、淡々と）。結果はだいたい裏目に出る。**PR回はここに商品が入る** |
| 41〜45 | オチ | クスっとさせる一言や絵（下の「オチの型」から1つ） |
| 45〜50 | 締め | 「…まあ、いいんです。パパなので。」。最後のカットを冒頭のフックにつなぐとループ再生されやすい |

短いほど最後まで見られやすいので、ネタが薄い回は無理に60秒に伸ばさない。

## 長尺（3〜5分）の型
1. 時報とタイトルコール（15秒）
2. エピソード2〜3本。ショートの型をそれぞれ1分〜1分半に伸ばす
3. 締め：「…まあ、いいんです。パパなので。」
4. お便り紹介：視聴者コメントを1〜2件読み、パパが一言返す
5. 締めの質問：「あなたの家でも、パパだけ後回しにされているもの、ありますか？」

反応の良かったショートを長尺にするのが基本。

## 企業案件（PR回）
- 商品は「対処と結果」パートに、パパが仕方なく使うものとして出す。話の流れは普段と同じにする
- 商品で悲哀が少しだけましになるが、オチは変えない（例：乾燥機でパンツはふかふかになったが、家族が自分の服を先に入れるので結局パパの番は夜中）。売り込みすぎない
- 冒頭と概要欄に「PR」「〇〇提供」と表示し、YouTubeの「有料プロモーション」にもチェックを入れる（ステマ規制の対応）

**ネタと相性の良い業種**

| ネタ | 業種 |
|---|---|
| パンツの一夜干し、雨続きでパンツがない | 衣類乾燥機、浴室乾燥、部屋干し用洗剤、下着 |
| キッチンはお湯を沸かすだけ | 電気ケトル、キッチン家電、ミールキット |
| 往復3時間の高速通勤 | 車、カー用品、コーヒー、オーディオブック、腰痛クッション |
| 焼肉の日だけ支払い係 | 飲食チェーン、キャッシュレス決済、ポイント |
| 期限切れのお菓子 | お菓子メーカー |
| 義父の優しさ、同居 | 住宅メーカー、保険、父の日ギフト、シニア向け商品 |
| 息子が義父のスマホを使う | 見守り・ペアレンタルコントロール、キッズ向けサービス |

## ネタ帳（実話ストック）
1. キッチンをリフォームしたら、妻に「汚れるから」とお湯を沸かす以外禁止された
2. 息子がクレーンゲームでお菓子を大量にゲット。頂戴と言ってもくれないが、賞味期限が過ぎたらくれる
3. 庭のバーベキューは焼きそばの段階から呼ばれるので、肉が食べられない
4. 焼肉キングに行くときだけ、支払い係として誘われる
5. 洗濯物の優先順位が低いので、雨が続くと翌日はいていくパンツがない → 会社で「明日履くパンツがないので帰ります」と言って残業を断り、定時で帰って会社近くのコインランドリーで洗濯してから帰宅（動画化済み：`episodes/ep02-ashita-no-pants/`）
6. 洗われても夜に洗われるので、冬は深夜の外に干されて、ほぼイカの一夜干し（`episodes/ep01-ichiyaboshi/` 試作。後半は実話待ち）
7. 毎朝6時前に出発、片道1時間半の高速通勤。家で起きている家族を見たことがない
8. 息子が義父のスマホでゲームやYouTubeを見ている（妻に使用時間がバレないため）
9. 息子が義姉と義父を遊びと買い物に付き合わせる

新しいネタを受け取ったら、この表に足すよう提案する。

## 1本作るときの手順
1. ネタを受け取る。足りない情報（いつ・誰が・パパの一言・オチになりそうな一言や出来事）は1回でまとめて聞く
2. ショートの型で台本を表にする（列：秒／パート／ナレーション・セリフ／絵）
   - ナレーションはパパ本人が読む前提で書く。1秒あたり約6文字、全体で60秒以内
   - 決め台詞（時報・パパなので）が入っていて、最後がクスっとするオチになっているか確認する
3. 添えるもの
   - タイトル案3つ（数字と具体性を入れる。例：「往復3時間通勤のパパ、パンツが一夜干しになる」）
   - サムネの一言（長尺のみ。8文字以内）
   - 概要欄（2〜3行と、ハッシュタグ 3〜5個：#パパの悲哀 #家庭内序列 #サラリーマン など）
   - 固定コメントの質問（例：「あなたの家でも、パパだけ後回しにされているもの、ありますか？」）
4. ユーザーに見せて、直しがあれば反映する

## 動画にする（アニメーション）
キャラは `assets/characters.js`（SVG）。見た目の一覧は `assets/charsheet.png`。
- `Chars.place(id, x, y, 倍率, {expr, pose, outfit, flip})`：全身を足元基準で置く
- `Chars.placeHead(id, x, y, 倍率, {expr})`：顔だけ（ボードや一覧の中など）
- id：`papa` `tsuma` `musuko` `ane` `gifu` `kohai`（会社の後輩・モブ）
- expr：`tired` `normal` `shock` `sad` `cry` `happy` `gentle` `smug` `strong` `sleep`
- pose：`down` `droop` `up` `hold` `point` `wave`
- outfit：`suit` `suitGray` `pajama` `apron` `tshirt` `oshi` `cardigan`

手順：
1. 前の回のフォルダ（例 `episodes/ep01-ichiyaboshi/`）をコピーし、`script.md` と `episode.html` の `LINES`・`scene(...)` を書き換える
   - 画面は 1080×1920。上 200px がヘッダー、200〜1380 が場面、その下がテロップ
   - 「時報」「パパなので」の2場面は演出を変えずに使い回す（中の数字や文字だけ変える）
   - テロップの5番目の要素で話している人を変えられる（例：`[41.5, 45, "…", "", "後輩"]`）
   - YouTube の右側ボタンと下部の文字に隠れないよう、大事な絵は場面の中央〜左に置く
2. フォントを用意（初回だけ）：`python ../beat-motion-video/scripts/fetch_fonts.py --out assets/fonts "Zen Maru Gothic:wght@500;700;900" "Dela Gothic One"`
3. 静止画で確認：`NODE_PATH=$(npm root -g) node scripts/render.mjs --html episodes/<回>/episode.html --stills 1,6,12 --scale 0.5 --out work/stills`
4. 書き出し：`NODE_PATH=$(npm root -g) node scripts/render.mjs --html episodes/<回>/episode.html --out episodes/<回>/out/<名前>.mp4`
   - パパの声があれば `--audio voice.m4a` を足す。無ければ無音で書き出す
   - 60秒で3分ほどかかる

## 量産型と判定されないためのチェック
- [ ] ネタが実話（ネタ帳の内容か、ユーザーから聞いた話）
- [ ] ナレーションはパパ本人の声（AI音声だけにしない）
- [ ] 絵はオリジナルのキャラ（いらすとやなどのフリー素材を主役にしない）
- [ ] 毎回、話の中身と絵が違う（使い回すのは型と決め台詞だけ）
- [ ] 投稿は週2〜3本まで。毎日の大量投稿はしない
- [ ] ときどき制作の裏側を見せる（例：通勤の車内で声を録っている）
