# 「明日履くパンツがない」台本（ショート44秒・ナレーション入り完成版）

ネタ帳 5（雨が続くと翌日はいていくパンツがない）の実話。
実際にあったこと：前日の夜、風呂に入るときにパンツが残り少ないと気づく。次の日、会社で「明日履くパンツがないので帰ります」と言って残業を断り、定時で帰って会社近くのコインランドリーで洗濯してから帰宅した。相手は年下の上司（元後輩）。パパの家での扱いを知っているので「いつも大変ですね」という反応。
脚色したところ（本人了承済み）：コインランドリーで洗ったのは実際は洗濯物ひと通りだが、動画では「パンツだけ」にした。次の日の朝の年下上司の「ちゃんときれいなパンツ履いてきました？」はオチとして足した。

ナレーションは Higgsfield の音声合成（Seed Audio、日本語男性ボイス「太郎」）で作った。年下上司は同じ声の高さを上げて区別している。
場面とテロップの時刻は、各行の音声の長さから `episode.html` の `PLAN` で自動で決まる。

## 投稿用

**タイトル案**
1. 「明日履くパンツがないので帰ります」と言って定時で帰った話
2. 往復3時間通勤のパパ、パンツのために残業を断る
3. 【実話】雨が3日続くと、パパのパンツがなくなる

**概要欄**
> 妻の実家で5人暮らし。家庭内序列は、いつも最下位。
> 毎朝6時前に家を出て、高速で片道1時間半のパパの実話です。
> #パパの悲哀 #家庭内序列 #サラリーマン #あるある #マスオさん

**固定コメント**
> あなたの家でも、パパだけ後回しにされているもの、ありますか？

## 書き出し方
1. 各行の音声（`f_00.opus` など、`episode.html` の `VOICE` に書いた名前）を1つのフォルダに置く
2. `NODE_PATH=$(npm root -g) node ../../scripts/render.mjs --html episode.html --voice-dir <音声フォルダ> --out out/ashita_no_pants.mp4`
3. 声を自分の声に差し替えるときは、同じファイル名で録音を置き、`VOICE` の長さ（秒）を録音の長さに直す
