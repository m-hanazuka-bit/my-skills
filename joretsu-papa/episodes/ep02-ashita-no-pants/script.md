# 「明日履くパンツがない」台本（ショート50秒）

ネタ帳 5（雨が続くと翌日はいていくパンツがない）の実話。
実際にあったこと：明日履くパンツがないので、残業を断って定時で帰り、会社近くのコインランドリーで洗濯してから帰宅した。会社では「明日履くパンツがないので帰ります」と言って帰った。

ナレーションはパパ本人が読む。秒数に合わせて、テロップと同じ文を読めばよい。

| 秒 | パート | ナレーション（＝テロップ） | 絵 |
|---|---|---|---|
| 0〜3 | フック | 「明日履くパンツがないので、帰ります。」 | 夕方の会社。定時の時計。無表情のパパの吹き出し。「実話」 |
| 3〜9 | 時報 ★ | 現在、午前4時50分。家族はまだ、誰も起きていません。 | 「― その日の朝 ―」。時計「AM 4:50」。寝ている妻と息子 |
| 9〜14 | 事件 | シャワーを浴びようとしたら、パンツが、最後の1枚。 | 脱衣所。妻と息子のかごは洗濯物でいっぱい、「パパ」のかごには「ラスト1枚」。「ガーン」 |
| 14〜18.5 | 事件 | 雨が3日続いた我が家。洗濯の順番は、序列のとおり。 | 「雨 3日連続」。洗濯の優先順位ボードに1〜4位が並ぶ |
| 18.5〜22 | 事件 | パパのパンツは、いつも最後です。 | 5位「パパのパンツ」がドスンと出る。スタンプ「いつも最後」 |
| 22〜26 | 事件 | 部屋干しの場所も、家族の服でいっぱい。 | 雨の窓。物干しに家族の服（体操服、推しTシャツなど）。パパのパンツはかごで「順番待ち」 |
| 26〜30 | 対処 | このままでは、明日履くパンツがない。 | 夕方の会社。時計と「定時」 |
| 30〜33 | 対処 | 「明日履くパンツがないので、帰ります。」 | 冒頭と同じ吹き出し（ここで冒頭の意味が分かる） |
| 33〜37 | 結果 | 残業を断り、会社近くのコインランドリーへ。 | コインランドリー。乾燥機の前で待つパパ |
| 37〜41 | オチ | 大きな乾燥機の中で、パパのパンツだけが回っている。 | 乾燥機の窓にズームすると、パンツが数枚だけ回っている。「ぐるぐる」 |
| 41〜45 | 結果 | それから片道1時間半かけて、家に帰った。 | 夜の高速。助手席に洗濯物の袋。「片道1時間半」 |
| 45〜50 | 締め ★ | …まあ、いいんです。パパなので。 | スポットライトの中で泣くパパ。最後に冒頭の会社に戻る（ループ） |

★ = 毎回使う決め台詞

## 確認したいこと（実話に合わせるため）
- 朝の時点で「最後の1枚」だったか（それとも別のタイミングで気づいたか）
- 会社で「帰ります」と言ったとき、言った相手（上司など）と、相手の反応
- コインランドリーで洗ったのはパンツだけか、ほかの洗濯物もあったか

## 投稿用

**タイトル案**
1. 「明日履くパンツがないので帰ります」と言って定時で帰った話
2. 往復3時間通勤のパパ、パンツのために残業を断る
3. 【実話】雨が3日続くと、パパのパンツがなくなる

**概要欄**
> 妻の実家で5人暮らし。家庭内序列は、いつも最下位。
> 毎朝6時前に家を出て、高速で片道1時間半のパパの実話です。
> #パパの悲哀 #家庭内序列 #サラリーマン #あるある #マスオさん

**固定コメント**
> あなたの家でも、パパだけ後回しにされているもの、ありますか？

## 声の入れ方
1. スマホのボイスメモで、表のナレーションを秒数に合わせて読む（多少ずれてもOK）
2. 書き出しのときに音声を渡す：
   `NODE_PATH=$(npm root -g) node ../../scripts/render.mjs --html episode.html --audio voice.m4a --out out/ashita_no_pants.mp4`
