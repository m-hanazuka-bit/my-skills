# 「ガソリン代が、交通費より高い。」台本（ショート約40秒）

ネタ帳 12（妻が欲しがって買ったミニバンに、パパしか乗らない）の実話。焼肉キングの話（ネタ帳 4）は、ネタを節約するため別の回（`episodes/ep13-yakiniku/`）に分けた。
実際にあったこと：妻がセレナ（ミニバン）を「欲しい」と言って買った。ところが義父が新車の N-BOX（軽自動車）を買ってからは、新しい方がいいので誰もセレナに乗らなくなった。そのあとパパは本社勤務になり、遠距離通勤（毎朝6時前に出発、高速で片道1時間半）に。燃費の悪いミニバンで通っているので、会社から支給される交通費より、ガソリン代の方が高い。そろそろ燃費の良い車に乗り換えようかな、と思っている。
脚色したところ：
- 「午前5時50分」は、ネタ帳 7（毎朝6時前に出発）に合わせた仮の時刻
- 「妻が選んだ車に、一番乗っているのはパパ」は、実話から言える事実をオチの言い方にしたもの
- 動画では車名・ロゴは出さず、「ミニバン」と「軽自動車」の絵にする。ガソリン代・交通費の金額は出さない
- 会社の場面はなし
