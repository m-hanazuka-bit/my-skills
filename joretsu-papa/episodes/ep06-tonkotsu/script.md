# 「シャワーだけ浴びて」台本（ショート約42秒）

ネタ帳 11（においの強いものは家の中で食べられない）の実話。
実際にあったこと：妻と息子は鼻が敏感で、家の中ではにおいの強いものが食べられない。真夏の暑い日、義父はカップの豚骨ラーメンを、庭にイスを置いて外で食べていた。パパのチキンラーメンは、ギリギリ家の中で食べられた。
脚色したところ：
- 主役のパパの悲哀にするため、パパと義父を入れ替えた（パパが庭で豚骨、義父が家の中でチキンラーメン。本人了承済み）
- オチの「においが残ってるから、シャワーだけ浴びて」は創作（実際はにおいが残ったまま過ごした。本人了承済み）
- 「気温35度」「午後0時」は仮の数字。「家の中は、エアコンが効いています」は、庭との差を見せるための演出
