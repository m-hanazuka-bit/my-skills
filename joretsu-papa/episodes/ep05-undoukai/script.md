# 「なんで来たの？」台本（ショート約48秒）

ネタ帳 15（息子の運動会を、学校のスピーカーの音で知る）の実話。
実際にあったこと：息子の運動会があることを、家族の誰も教えてくれない。小学校が近いので、休みの日に家にいると、学校から聞こえてくるスピーカーの音で初めて運動会だと知る。見に行ったら、妻と義姉と義父が、息子のクラスの席のうしろにレジャーシートを敷いて普通に応援していた。パパに気づいて「なんで来たの？」と言われた。たまたま休みでなかった年は、運動会があったことも知らない。
脚色したところ：
- 「午前9時」は仮の時刻
- スピーカーの「位置について、よーい…」は演出（実際に聞こえた内容は未確認）
- 「なんで来たの？」を言ったのは妻にした（実際に誰が言ったかは要確認）
- 家族のカレンダーでパパの欄だけ空白の絵、レジャーシートにパパの座る場所がない絵は演出
