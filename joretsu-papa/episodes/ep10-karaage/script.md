# 「パパの唐揚げは、3個」台本（ショート約38秒）

ネタ帳 16（息子がよく食べた日は、パパの分が減る）の実話。
実際にあったこと：ふだん少食の息子が予想外にたくさん食べた日は、パパのご飯がちょこっとしか残っていない。お弁当屋さんの唐揚げ弁当の日は、パパの弁当の唐揚げが3個くらいに減っていた。食べたのは息子。
脚色したところ：
- 「午後9時」は仮の時刻
- 息子の口のまわりに唐揚げの衣がついている絵は演出
- 店名・ロゴは出さず「お弁当屋さんの唐揚げ弁当」にする

## 台本

冒頭の大きな文字（0〜2.5秒。`plan.json` の `hook`）：**唐揚げ／3個**

| 秒 | パート | ナレーション・セリフ | 絵 |
|---|---|---|---|
| 0〜4 | フック | パパの唐揚げ弁当。なぜか、すき間がある。 | ふたを開けたお弁当を見て固まるパパ。唐揚げのあいだにすき間。「実話」 |
| 4〜8 | 時報 ★ | 現在、午後9時。家族はもう、晩ごはんを食べ終わっている。 | 暗いダイニング。時計「PM 9:00」。テーブルに弁当が1つ |
| 8〜13 | 事件 | 今日の晩ごはんは、お弁当屋さんの唐揚げ弁当。 | テーブルに並ぶ空の弁当容器 |
| 13〜19 | 事件 | 息子は、ふだん少食。でも今日は、珍しく、よく食べた。 | 回想。唐揚げをほおばる息子、喜ぶ妻 |
| 19〜24 | 結果 | パパの唐揚げは、3個。 | お弁当を上から見た絵。唐揚げが3個だけ |
| 24〜30 | オチ | 食べたのは、息子。 | ソファで満足そうに寝ている息子。口のまわりに唐揚げの衣 |
| 30〜38 | 締め ★ | …まあ、いいんです。パパなので。 | スポットライトの中で、3個の唐揚げを大事に食べるパパ。冒頭のお弁当に戻る（ループ） |

★ = 毎回使う決め台詞。（）のないセリフは語り手（Emily）

秒数は目安（実際の長さは声の長さで決まる）。前の版から詰めたところ：前のフック「パパの唐揚げの数は、息子の食欲で決まる」はオチ（食べたのは息子）を先に言ってしまっていたので、「なぜか、すき間がある」に変えて、答えを最後まで取っておくようにした。冒頭の大きな文字（唐揚げ／3個）はそのまま。
