# 「お会計が高い日だけ、呼ばれる。」台本（ショート約30秒）

ネタ帳 4（焼肉キングに行くときだけ、支払い係として呼ばれる）の実話。もとは車の回（`episodes/ep04-kuruma/`）に入れていたが、ネタを節約するため1本に分けた。
実際にあったこと：ふだん家族は、義父・妻・義姉・息子の4人でごはんを食べに行く。お会計が高いとき（焼肉キングなど）だけ、パパも呼ばれる。4人がどこかへ出かけてしまったときは、パパは1人で近所のラーメン屋さんへ行く。たまにスープ切れで早く閉まっていて食べられず、仕方なくコンビニに行ったことがある。
脚色したところ：
- 「午後6時」は仮の時刻
- 「軽自動車にちょうど4人」は、ep04 の車の話とつなげるための一言（4人で出かけるときの車は要確認）
- コンビニで買ったものは仮（実際に何を買ったかは未確認）
- 動画では焼肉キング以外の店名・ロゴは出さず、「近所のラーメン屋さん」「コンビニ」にする。ラーメン屋さんは「スープがなくなるほど人気のお店」として好意的に描く
