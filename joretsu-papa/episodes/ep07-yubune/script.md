# 「ホテルに泊まれるなら、どこでも行きます」台本（ショート約48秒）

ネタ帳 10（湯船はパパだけ使用禁止）の実話。
実際にあったこと：お風呂をリフォームしたが、湯船を使うと水道代とガス代が上がったので、パパは湯船の使用禁止に。妻には「水道代がもったいない」と言われた。妻と息子はたまに湯船に入っている。こっそり湯船を使っていたらバレて、湯船の栓を抜いて隠された。今も使えない。出張でホテルに泊まるときだけ湯船に入れるので、そういうときは3時間ぐらい湯船につかって、スマホを見ている。泊まるのは安いビジネスホテルのユニットバスだけ。それでも最高。会社には「ホテルに泊まれるなら、どこでも行きます」と言ってある。
脚色したところ：
- 30代課長のセリフ（出張のお願い、「いつも引き受けてくれて助かります」）とパパの返事「…いえ。」は、オチとして作った
- 「午後11時」は仮の時刻
