# 第1話「一夜干しパパ」台本（ショート50秒）

ネタ帳 6（冬の夜に干されて一夜干し）より。

> **保留中**：30秒以降（シートヒーターで解凍、後輩の一言）は仮で作った話。実際にどうなったかを聞いて作り直す。
> 雨続きでパンツがなくなった話は、別の回「明日履くパンツがない」（`../ep02-ashita-no-pants/`）にした。
ナレーションはパパ本人が読む。秒数に合わせて、テロップと同じ文を読めばよい。

## 投稿用

**タイトル案**
1. 往復3時間通勤のパパ、パンツが一夜干しになる
2. 【実話】真冬の夜に干されたパパのパンツ、ほぼイカだった
3. 洗濯の順番がいつも最後のパパ、会社でイカ焼きの匂いがする

**概要欄**
> 40代係長。妻の実家で5人暮らし。家庭内序列は、いつも最下位。
> 毎朝6時前に家を出て、高速で片道1時間半のパパの実話です。
> #パパの悲哀 #家庭内序列 #サラリーマン #あるある #マスオさん

**固定コメント**
> あなたの家でも、パパだけ後回しにされているもの、ありますか？

## 声の入れ方
1. スマホのボイスメモで、表のナレーションを秒数に合わせて読む（多少ずれてもOK）
2. 書き出しのときに音声を渡す：
   `NODE_PATH=$(npm root -g) node ../../scripts/render.mjs --html episode.html --audio voice.m4a --out out/ep01.mp4`
3. 音声に合わせて場面の秒数を直したいときは、`episode.html` の `LINES` と `scene(開始, 終了, …)` の数字を変える
