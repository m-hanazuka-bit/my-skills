# 「パパの得意料理は、お湯です」台本（ショート約49秒）

ネタ帳 1（キッチンをリフォームしたら、お湯を沸かす以外禁止された）の実話。
実際にあったこと：1年前にキッチンをリフォームした。最初は炒め物や焼き魚を作っていたが、汚れるたびに掃除をして、少しでも汚れが残っていると怒られた。それが大変になると料理禁止になった。今はカップラーメンだけ。グリルの排気口にはほこりよけのカバー、ガスコンロは3口あるが2口には平らな板のカバー（天板タイプ）がかぶせてあり、使えるのは1口だけ。グリルの排気口カバーは奥の細長い板。
脚色したところ（本人了承済み）：次の日の30代課長の2つのセリフ（「リフォームしたのに使えないんですか…大変ですね」「うちも先月リフォームして、毎晩僕が作ってます」）と、パパの返事「…お湯は、沸かせます。」はオチとして作った。お湯は使える1口でやかんで沸かす形にした。
