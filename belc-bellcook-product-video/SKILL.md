# ベルクックさんの商品紹介動画

共通エンジン `../belc-product-video/`（手順の詳細は `WORKFLOW.md`）を、ベルクックさんの設定 `characters/bellcook/character.json` で動かす。
このファイルには**ベルクックさんらしさの作り方**だけを書く。

## ベルクックさんってこんな人（設定表より）
- 落ち着いていて優しい、きちんとした話し方のお姉さんタイプ。やわらかく澄んだ声で、決して声を張らない
- 一人称は「私」。「〜です」「〜ます」の丁寧語。人前が少し苦手なので、**煽らず控えめ**
- 今日のレシピ提案や、おすすめ食材・お買い物のコツを丁寧に紹介する人
- 声：Gemini TTS `Leda`／Style: Conversational / Polite & Gentle／Pace: ゆったり一定、自然な息づかい／誇張した宣伝口調は避ける
- **禁止**：語尾「〜わよ」「〜かしら」、感嘆符の連発、「激安」「ヤバい」などの強い言葉

## 受け取るもの
1. **商品画像**（必須）：パッケージの実物写真。白背景でも可、高さ 1000px 以上が理想
2. **商品情報**：商品名・規格・推しポイント 1〜3 個・（あれば）価格
3. **ナレーション案**（モード①・おすすめ）か**作成済みの音声ファイル**（モード②）
4. （任意）使い方・レシピのヒント（なければ一般的でありふれた使い方から 1 つ選ぶ。健康効果はうたわない）

足りなければ 1 回でまとめて聞く。ナレーション案が無ければ商品情報からこちらで書く。

## 台本の作り方（モード①）
ナレーション案を、下の型に沿ってベルクックさんの口調に直す。**意味と事実は変えない**。

| # | scene | emotion | 役割 | 例（酪農牛乳） |
|---|---|---|---|---|
| 1 | hook | odayaka | あいさつ | こんにちは、ベルクックです。 |
| 2 | product | ureshii | 商品名をそっと紹介 | 今日は*酪農牛乳*をご紹介します。 |
| 3 | point | kotsu | 推しポイントを落ち着いて | 成分無調整で、生乳100%使用です。 |
| 4 | point | teian | 使い方・レシピの提案（彼女らしさの核） | 私は、朝のカフェオレに使います。 |
| 5 | closing | shime | やわらかく締める | お買い物のついでに、ぜひどうぞ。 |

- 4〜5 行、1 行 30 文字以内、合計 13〜17 秒（1 秒 ≒ 6 文字。ゆっくりでよい）
- 盛り上げの山は作らない。4 行目の「提案」でいちばん温かくする
- 感嘆符は動画全体で 1 回まで。「〜ですね」「〜ますよ」で親しみを出す
- 数字の読み：「100%」は `read` に「ひゃくパーセント」と書くと確実

書けたら**台本を表にしてユーザーに見せ**（行・セリフ・シーン）、そのまま次へ進む（直しの指示があれば反映）。

## 作る
```bash
E=<skills>/belc-product-video
python $E/scripts/prepare_assets.py 商品写真.jpg work/product.png
python $E/scripts/check_lines.py --character $E/characters/bellcook/character.json --script work/script.json --target 18
python $E/scripts/make_video.py --character bellcook --script work/script.json --out work/<商品名>_bellcook --draft
#  → コンタクトシートで確認 → 本番（--draft を外す、縦型は --vertical）
```
モード②（音声持ち込み）は `--audio ベルクック.wav` を足す。

## 仕上がりチェック（ベルクックさん版）
- [ ] 動きが控えめ（大きく跳ねない、ゆっくり息をするくらい）。BGM は lofi で声より前に出ていない
- [ ] 丁寧語で終わっていて、「〜わよ」「〜かしら」が無い（`check_lines.py` が ERROR を出す）
- [ ] 提案の行（teian）で、商品とひとことが画面に大きく出ている
- [ ] 締めに商品名・規格・ポイント・「くらしにベルク」が 1.5 秒以上出ている
- [ ] 声が宣伝口調になっていたら `--retts <id>`。行の `direction` に「もっと小さく、ささやくほどではなく穏やかに」などを足す

## 画像について
いま手元にあるのは三面図（正面・横・後ろ）からの切り抜き（`characters/bellcook/bellcook_front.png`、`bellcook_side.png`）。
シーン画像（売場やキッチンに立つベルクックさん）があれば、scene `photo` に `image` で入れられる。生成画像で商品を持たせた場合は、ぐぅと同じく `cover` で実物のパッケージに置き換える。

作例：`../belc-product-video/examples/rakuno-milk/script_bellcook.json`
