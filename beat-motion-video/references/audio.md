# 音：ビートと声のテンション設計

## ビート（make_beat.py）
外部音源なしで numpy 合成するので、著作権と API キーの心配がない。`--list` で一覧。

| style | 既定 BPM | 性格 | 向く作風 |
|---|---|---|---|
| house | 124 | 4 つ打ち。明るく前向き | 商品紹介、テック、night-city |
| trap | 140 | ハーフタイムの 808、ハイハットのロール | ストリート、ゲーム、terminal |
| lofi | 84 | スウィング＋和音パッド＋レコードノイズ | 和・上質、カフェ、doodle |
| cinematic | 100 | 太鼓、インパクト、ライザー | 高級感、予告編、wa-premium |
| future | 128 | ビルドアップ → ドロップが一番派手 | SNS 広告、sport-pop、イベント |

- 小節数は `round(秒 × BPM / 240)`。15 秒なら 6〜9 小節。**シーンの境目は必ず小節線**（`start_bar` / `end_bar` は整数）
- セクションは自動で intro(25%) → build(20%) → drop(残り) → outro(1 小節)。`timeline.json` の `sections` と `drop_time` を見る
- **ドロップの頭（drop_time）に一番見せたい絵を置く**：3D の主役の登場、メインコピー、ロゴのどれか
- 映像の反応の割り当て（テンプレートと blender_scene.py が既にこうなっている）：

| 音 | 映像 |
|---|---|
| kick（キック） | スケールパンチ、背景の明るさ、発光、強調語の脈動 |
| snare（スネア／クラップ） | 主役がカクッと回る、擬音・ステッカーが弾む |
| impact（インパクト） | 白フラッシュ、カメラシェイク、リムライトの点滅、シーンの頭 |
| 8 分音符 | タイポが 1 文字ずつ出る間隔 |
| riser（ライザー） | ワイプの溜め、カメラの寄り |

- 曲の差し替え：手持ちの楽曲を使うなら `make_beat.py` の JSON だけ流用し、BPM と頭の位置を合わせて `beat.wav` を置き換える
  （BPM が不明なら Premiere の `pr_detect_beats` などで検出して `kicks` を作る）

## 声（gemini_tts.py）
Gemini TTS は「どう読むか」を自然文で指示できる。1 行ずつ別々に生成し、行ごとにテンションを変えて**感情の起伏**を作る。

### テンション（`--list-tensions`）
| id | Lv | 既定の声 | 指示 |
|---|---|---|---|
| whisper | 1 | Kore | 耳元でささやく、息多め、ゆっくり |
| calm | 2 | Kore | 落ち着いた低め、上品、間をたっぷり |
| warm | 2 | Sulafat | やわらかく温かい、微笑みながら |
| narrator | 3 | Charon | ドキュメンタリーのナレーター、明瞭 |
| tagline | 3 | Kore | 締めのキャッチコピー、きっぱり、余韻 |
| build | 4 | Fenrir | 期待を高める、少しずつ力強く、前のめり |
| bright | 4 | Puck | 明るく弾む、テンポ良く |
| hype | 5 | Fenrir | ライブの MC、エネルギー全開 |
| trailer | 5 | Algenib | 映画予告、低く太く一語一語に重み |

### テンションカーブの作り方
1. ビートのセクションに合わせて山を 1 つ作る：intro は Lv1–3、build で Lv4、drop で Lv5、outro で Lv3 に戻す
2. **山の直前に一番低い行を置く**と落差で盛り上がる（whisper → hype）
3. 1 本の動画では声（voice）は基本 1 人に固定し、テンションだけ変える。`voice.name` で固定、行ごとに `voice` で上書き可
4. 細かいニュアンスは行の `style` に足す：`"style": "語尾を少し上げて問いかけるように"`
5. 1 行は **1〜2 小節に収まる長さ**（目安：日本語 1 秒 ≒ 6〜7 文字）。生成後 `voice/voice.json` の duration を見て、はみ出すなら文を削るか `at_bar` を前へ
6. 字幕の強調は `*語*` で書く（読み上げ時は * を自動で外す）。字幕だけ変えたいときは `caption` に別文を書く

### モデルとキー
- キーは環境変数 `GEMINI_API_KEY`、またはスキル直下の `.env`（`.env.example` をコピー）。**キーを storyboard や SKILL.md に書かない**
- モデルは `--model` か環境変数 `GEMINI_TTS_MODEL`。既定は `gemini-3.8-flash-tts`
- 出力は 24kHz モノラル。ミックス時に 48kHz へ変換、声の間はビートを自動で 45% に下げる（`--duck`）

### ミックスの調整（mix_audio.py）
- 声が埋もれる → `--duck 0.3` か `--beat-gain 0.6`
- ビートが弱い → `--beat-gain 1.0 --duck 0.6`
- セリフの頭は 8 分音符にスナップされる（`--no-snap` で無効、`at` で秒を直接指定も可）
