# ぐぅの商品紹介動画

共通エンジン `../belc-product-video/`（手順の詳細は `WORKFLOW.md`）を、ぐぅの設定 `characters/gu/character.json` で動かす。
このファイルには**ぐぅらしさの作り方**だけを書く。

## ぐぅってこんな子（設定表より）
- 生意気で目立ちたがりの若いオスのペンギン。明るく少年っぽい、少しハスキーな声。早口の関西弁
- 一人称は「俺」。語尾は「〜やで」「〜やし」「〜わ」「ほんま」
- 商品のよさを「**俺が見つけてきたんやで！**」という自分の手柄として語る。張り切りすぎて少し空回り、でも憎めない
- 声：Gemini TTS `Callirrhoe`／Style: Cocky Promo / Show-off／Pace: 早口、自慢の直前に劇的な間

## 受け取るもの
1. **商品画像**（必須）：パッケージの実物写真。白背景でも可、高さ 1000px 以上が理想
2. **商品情報**：商品名・規格（容量）・推しポイント 1〜3 個・（あれば）価格。パッケージから読み取れる範囲なら画像から拾ってよい
3. **ナレーション案**（モード①・おすすめ）か**作成済みの音声ファイル**（モード②）
4. （任意）ぐぅがその商品と写っているシーン画像。生成画像なら商品の文字が崩れているので `cover` で実物に置き換える

足りなければ 1 回でまとめて聞く。ナレーション案が無ければ商品情報からこちらで書く。

## 台本の作り方（モード①）
ナレーション案を、下の型に沿ってぐぅの口調に直す。**意味と事実は変えない**、足してよいのは口調と演技だけ。

| # | scene | emotion | 役割 | 例（酪農牛乳） |
|---|---|---|---|---|
| 1 | hook | tame | 呼び止める・ためる | おっ、ちょお待ってや！ |
| 2 | product / photo | doya | 「俺が見つけた」宣言＋商品名 | 俺が見つけてきた、*酪農牛乳*やで！ |
| 3 | point | hype | 一番の推しポイントを一気に | *成分無調整*、生乳100%使用や！ |
| 4 | photo / point | sneaky | 内緒話っぽく魅力をもう一押し（省略可） | 牧場のうまさ、そのまんまやねん。 |
| 5 | closing | shime | 規格＋決めゼリフ | 1000ml、ほんまにおすすめやで！ |

- 4〜5 行、1 行 26 文字以内、合計 12〜15 秒（ぐぅは早口なので 1 秒 ≒ 8 文字）
- テンションの山は 3 行目。1 行目で一瞬ためてから 2 行目で胸を張る
- 使える口癖：見てみぃ／ほんま／めっちゃ／〜やん／〜やろ？／俺の目に狂いはないで／知らんかったやろ？
- 使わない：標準語の丁寧語（です・ます）、「僕」「私」、根拠のない「日本一」「最高」
- 数字の読み：「1000ml」は `read` に「せんミリリットル」と書くと確実

書けたら**台本を表にしてユーザーに見せ**（行・セリフ・シーン）、そのまま次へ進む（直しの指示があれば反映）。

## 作る
```bash
E=<skills>/belc-product-video
python $E/scripts/prepare_assets.py 商品写真.jpg work/product.png          # 商品の切り抜き
python $E/scripts/check_lines.py --character $E/characters/gu/character.json --script work/script.json
python $E/scripts/make_video.py --character gu --script work/script.json --out work/<商品名>_gu --draft
#  → コンタクトシートで確認 → 本番（--draft を外す、縦型は --vertical）
```
モード②（音声持ち込み）は `--audio ぐぅ.wav` を足す。台本の行数に合わせて無音で自動分割される。区切りの秒数一覧を見て、ずれていれば `align_audio.py` を `--min-silence 0.2` などで回し直す。

## 仕上がりチェック（ぐぅ版）
- [ ] 1 行目の「ため」の後、2 行目の頭でぐぅが跳ねている（キックのホップ）
- [ ] doya / hype / shime の行でキラキラが出ている
- [ ] 実物パッケージが最低 2 シーンで大きく映る。生成画像の中の商品は実物で覆われている
- [ ] 締めに商品名・規格・ポイント・「くらしにベルク」が 1.5 秒以上出ている
- [ ] 声が関西弁で自慢げになっている（標準語っぽければ `--retts <id>` で作り直す。`emotion` を変えるか、行の `direction` に「もっと関西弁を強く、語尾を伸ばして」などを足す）

作例：`../belc-product-video/examples/rakuno-milk/script_gu.json`（酪農牛乳 1000ml、棚の生成画像を実物で上書きする例つき）
