# 例：十万石まんじゅう

元CM（約 20 秒）：尺八と小鳥の声のあと、年配男性のナレーション
「風が語りかけます。うまい、うますぎる。十万石まんじゅう。埼玉銘菓、十万石まんじゅう。」

| ファイル | 内容 |
|---|---|
| `script.txt` | 台本（元CMの書き起こし） |
| `style.txt` | 演出メモ |
| `profile.json` | 元CMから測った句の時刻・声の高さ・声質・スペクトル（元CMの音声そのものは入っていない） |

## 元CMの測定値
- 声の高さ 中央値 112Hz（10〜90% 範囲 75〜156Hz）。語尾で 75Hz 付近まで下がる
- 600〜1200Hz と 2400〜3200Hz が張っていて、4800Hz より上はほとんど無い（古いテレビCMの狭い帯域）
- 句の間：1.25 / 0.42 / 0.63 / 0.99 / 0.30 秒、ナレーション全体で約 10 秒
- 句の中と句の間の音量差 27dB（声の下に尺八の余韻）。HNR 6.2dB・shimmer 12% は実際の声より濁って出ている

## 採用した設定
- 声：**Algenib**（Gravelly）
- 後処理：`--drive 3.0`、`--husk 0`（かすれ 0.3〜1.2 も作って聴き比べたが、かすれなしに決まった）
- 採用ファイル：`audio/juumangoku/narration_Algenib_cm.wav`

```bash
python scripts/match_ref.py --profile examples/juumangoku/profile.json tts_Algenib.wav --drive 3 --husk 0
```

## 経緯（やり直しになった点）
1. 演出メモと台本を分けずに渡し、メモまで読み上げられた（3 行が 40 秒）
2. Charon / Algenib / Orus →「全部だめ」。声が低すぎ（77〜88Hz）、渋さ・濁りが足りないと言われ、候補を入れ替えた
3. 「波長とかちゃんと調べて」→ 元CMをもらって解析し、台本の思い込み違い・帯域の違い（TTS は高域が出すぎ）・間の長さが分かった
4. 間・高さ・EQ を後処理で合わせて OK。かすれは足さないことに決まった
